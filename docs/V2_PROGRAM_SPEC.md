# V2 Program Spec — Upper/Lower 8-Week Plan

## Four-day structure

Each week repeats this order:

| Slot | Label | Session | Duration |
| --- | --- | --- | --- |
| 1 | Upper A / Upper A2 | Workday | 35–45 min |
| 2 | Lower A / Lower A2 | Workday | 35–45 min |
| 3 | Upper B / Upper B2 | Off Day | 70–90 min |
| 4 | Lower B / Lower B2 | Off Day | 70–90 min |

32 sequential workouts across 8 weeks. Scheduling remains flexible (any workout openable anytime; Recommended Next = lowest incomplete order).

## Training blocks

| Weeks | Block | Notes |
| --- | --- | --- |
| 1–4 | Block 1 | Full Block 1 exercise selection |
| 5 | Deload (Block 1) | Same exercises; primary −1 set; accessories/core 2 sets; lighter loads; 3–4 RIR; no failure |
| 6–8 | Block 2 | Block 2 exercise selection |

### Week-by-week progression guidance

| Week | Phase | RIR / intent |
| --- | --- | --- |
| 1 | Block 1 — Technique & Base | 2–3 RIR, conservative loads |
| 2 | Block 1 — Base Volume | 2–3 RIR |
| 3 | Block 1 — Controlled Progression | 1–2 RIR |
| 4 | Block 1 — Peak Week | 1–2 RIR |
| 5 | Deload (Block 1) | 3–4 RIR, reduced sets |
| 6 | Block 2 — Controlled Introduction | 2–3 RIR |
| 7 | Block 2 — Progression | 1–2 RIR; add reps or load |
| 8 | Block 2 — Controlled Performance | ~2 RIR; no failure |

## Block 1 workouts

### Upper A — Workday

1. Machine Chest Press — 3 × 8–12 — `reps-weight` — primary
2. Neutral-Grip Lat Pulldown — 3 × 8–12 — `reps-weight` — primary
3. Chest-Supported Dumbbell Row — 3 × 10–12 — `reps-weight` — primary
4. Seated Dumbbell Shoulder Press — 2 × 8–12 — `reps-weight` — secondary
5. Dumbbell Hammer Curl — 3 × 10–12 — `reps-weight` — isolation
6. Rope Triceps Pushdown — 3 × 10–12 — `reps-weight` — isolation

Focus: Chest · Back · Shoulders · Biceps · Triceps

### Lower A — Workday

1. Leg Press — 3 × 10–12 — `reps-weight` — primary
2. Dumbbell Romanian Deadlift — 3 × 8–12 — `reps-weight` — primary
3. Seated Leg Curl — 3 × 10–12 — `reps-weight` — secondary
4. Seated Calf Raise — 3 × 12–15 — `reps-weight` — isolation
5. Dead Bug — 3 × 8–12 per side — `reps-only` — core

Focus: Quads · Hamstrings · Glutes · Calves · Core

### Upper B — Off Day

1. Incline Dumbbell Press — 4 × 8–10 — `reps-weight` — primary
2. Chest-Supported Row Machine — 4 × 8–10 — `reps-weight` — primary
3. Neutral-Grip Lat Pulldown — 3 × 10–12 — `reps-weight` — primary
4. Cable Fly — 3 × 12–15 — `reps-weight` — isolation
5. Dumbbell Lateral Raise — 3 × 12–15 — `reps-weight` — isolation
6. Reverse Pec Deck — 3 × 12–15 — `reps-weight` — isolation
7. Incline Dumbbell Curl — 3 × 10–12 — `reps-weight` — isolation
8. Overhead Cable Triceps Extension — 3 × 10–12 — `reps-weight` — isolation

Focus: Chest · Back · Shoulders · Biceps · Triceps

### Lower B — Off Day

1. Hack Squat — 4 × 8–10 — `reps-weight` — primary
2. Dumbbell Bulgarian Split Squat — 3 × 8–10 per side — `reps-weight` — secondary (unilateral)
3. Hip Thrust — 4 × 8–12 — `reps-weight` — primary
4. Seated Leg Curl — 3 × 10–12 — `reps-weight` — secondary
5. Leg Extension — 3 × 12–15 — `reps-weight` — isolation
6. Seated Calf Raise — 3 × 12–15 — `reps-weight` — isolation
7. Cable Pallof Press — 3 × 10–12 per side — `reps-weight` — core (unilateral)
8. Forearm Plank — 3 × 30–60 seconds — `duration` — core
9. Elliptical or Stationary Bike — 15–20 minutes — `cardio-duration`

Focus: Quads · Hamstrings · Glutes · Calves · Core

## Measurement types

| Type | Inputs | Used for |
| --- | --- | --- |
| `reps-weight` | reps + kg | Weighted machine/cable/dumbbell |
| `reps-only` | reps | Dead Bug |
| `duration` | seconds / set | Forearm Plank, Side Plank |
| `cardio-duration` | minutes + completed | Elliptical / Stationary Bike |

Also stored on each exercise: `unilateral`, `targetUnitLabel`, `equipmentCategory`, `primaryMuscles`, `secondaryMuscles`, `role`.

## Weekly muscle-volume targets (direct sets, normal weeks)

| Muscle | Target |
| --- | --- |
| Chest | 10–12 |
| Back | 12–14 |
| Shoulders | 7–10 |
| Biceps | 6 |
| Triceps | 6 |
| Quadriceps | 10–14 |
| Hamstrings | 8–10 |
| Glutes | 8–12 |
| Calves | 6 |
| Core | 6–9 |

Direct sets are counted from each exercise’s `primaryMuscles` only. Indirect pressing/pulling does **not** count as full direct arm sets. Deload week is expected to undershoot these ranges.
